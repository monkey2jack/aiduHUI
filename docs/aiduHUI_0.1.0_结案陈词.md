## 一、项目回顾与交付全景

**aiduHUI（爱嘟心视界）** 是基于开源项目 `EKKOLearnAI/hermes-studio` (v0.7.19) 进行派生裁剪重构的 **HERMES AGENT 专精智控工作台**。

按照猴哥确立的 Plan A 路线，成功实现：
1. **纯粹 10 核心板块**：一屏聚合通用模型、辅助模型、组合模型、上下文压缩、性能监控、用量统计、系统日志、定时任务、外部频道、技能记忆。
2. **VI 全链路贯通**：严格贯彻 aiduPARK 品牌三原色（深蓝 `#1f4e79`、暮灰 `#525252`、墨黑 `#000000`、宣白 `#ffffff`）与苹果系统字系，搭载三角晶格（Lattice）动态网格与随机 Slogan 动效。
3. **交互革新**：左侧卡片自适应分栏 + 中间微型分界线收缩拨钮（14×28px 零压边）+ 左下角注销登录（`退出/Log-Out`）+ 手机端折叠全收起模式。
4. **热生效能力保全**：前端 Vite HMR 与后端 nodemon 双向热生效无缝保全。

## 三、避坑与生产经验（SOP 增补）

1. **上游多 Agent 侧边栏回渗陷阱**：
   - 上游系统通过全局 `App.vue` 挂载了 `AppSidebar` 与历史配置侧栏。若未在根层彻底拦截 `showAppSidebar`，非工作台路由会导致旧侧栏回弹。
   - *对策*：在 `App.vue` 强制阻断全局侧栏挂载，路由全收敛至单一 `/workbench`。
2. **折叠拨钮的物理边距**：
   - 悬浮在分界线上的拨钮若尺寸超过间隙（gap 16px），会遮挡内侧卡片边框或文本。必须精简为 `14px` 宽度并向右微移，保持纯物理间隙居中。
3. **单密码登录体验与后端兼容**：
   - 后端必须兼容空用户名入参，自动按激活的 `super_admin` 哈希校验并签发 JWT，避免前端界面简化后后端接口报错。
4. **品牌矩阵定名约束**：
   - aidu 家族通讯插件官方正定中文名为 **`爱嘟泡波浪`**，文档与 SOP 必须严格对齐。
